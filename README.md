# Seniorenheim Auetal — Websystem V4 Premium Concept

Nicht „noch eine schönere Pflege-Website“, sondern ein zusammenhängendes Websystem für Angehörige **und** Mitarbeitergewinnung.

## Was gegenüber der ersten Version neu ist
- cinematischer Hero statt klassischem Landingpage-Stack
- große Employer-Branding-Typografie mit scrollgebundener Bewegung
- sticky Scrollytelling durch echten Auetal-Arbeitsalltag
- Pflege-Kompass für Angehörige
- 60-Sekunden-Job-Match für Bewerber
- Social-Recruiting-Landingpage
- visualisierter Systemfluss `Ad → Karrierewelt → Job-Match → Cockpit` mit animierten SVG-Verbindungen
- Job-Match-Demo kann einen Kontakt per `localStorage` sichtbar ins Recruiting-Cockpit übergeben
- Editorial Benefit Wall statt SaaS-Kartenoptik
- echte Auetal-Bilder und Auetal-spezifische Story
- Smooth Scroll via gepinntem Lenis 1.3.26 mit nativen Fallbacks
- reduced-motion, Keyboard-Fokus und Mobile-Fallbacks

## Kernstory
Die bestehende Auetal-Seite hat Substanz. V4 versucht nicht, sie künstlich schlecht aussehen zu lassen. Das Konzept zeigt stattdessen, was passiert, wenn die Website aktiv führt und Recruiting als System gedacht wird.

**Angehörige:** Orientierung → passendes Haus → Pflege-Kompass → persönlicher Kontakt.

**Bewerber:** Social Hook → Arbeitgebergefühl → reale Vorteile → offene Rolle → Job-Match → Kennenlernen/Probearbeiten → Demo-Cockpit.

## Fakten-Disziplin
Konkrete Konditionen wie 3.700 € Einstieg, 35 Urlaubstage und 500 € Jahresbonus werden ausschließlich im Kontext der dafür öffentlich ausgeschriebenen Pflegeassistenz-Stelle verwendet. Demo-KPIs und Demo-Leads im Cockpit sind ausdrücklich als nicht reale Daten gekennzeichnet.
